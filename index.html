Política de Privacidade

Quem é o Judas? — Jogo Bíblico

Última atualização: abril de 2026

Esta Política de Privacidade descreve como o aplicativo Quem é o Judas? trata as informações dos seus usuários.

1. Coleta de Dados

O aplicativo Quem é o Judas? não coleta, armazena, transmite nem compartilha nenhum dado pessoal dos usuários.

Todos os dados gerados durante o uso do aplicativo — como nomes de jogadores e pontuações — existem exclusivamente na memória do dispositivo durante a sessão de jogo e são apagados automaticamente quando o aplicativo é fechado.

2. Dados de Terceiros

O aplicativo não utiliza serviços de análise, publicidade, rastreamento ou qualquer SDK de terceiros que colete dados dos usuários.

3. Permissões

O aplicativo solicita apenas a permissão de acesso à Internet, necessária para o funcionamento técnico da estrutura Capacitor/WebView. Nenhuma conexão de rede é realizada para transmitir dados do usuário.

4. Crianças

O aplicativo é adequado para todas as idades e não coleta nenhum dado de crianças ou adultos.

5. Alterações nesta Política

Caso esta política seja alterada no futuro, a nova versão será disponibilizada nesta mesma página com a data de atualização revisada.
